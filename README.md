# Aromas Wi-Fi 🌟
**Aplicación de Gestión de Red Privada (Modo Nano)**

Esta aplicación está diseñada para gestionar una conexión Wi-Fi compartida con un límite estricto de seguridad.

### Funciones Principales:
* **Límite de 3 Personas:** Solo permite la conexión de los 3 dispositivos autorizados.
* **Conexión Automática:** Escanea y se conecta a la red más fuerte disponible.
* **Ahorro de Datos:** Corta el uso de datos móviles automáticamente para evitar cargos.
* **Interfaz Premium:** Diseño en dorado y negro con indicadores de estado en tiempo real.
